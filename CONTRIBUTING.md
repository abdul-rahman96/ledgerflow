# Contributing

LedgerFlow is a portfolio-grade clean-room project. Contributions must be original or compatible with the MIT license.

Before opening a pull request:

1. Run npm install, lint, typecheck, and build in apps/web.
2. Install apps/api with its dev extra, then run Ruff and pytest.
3. Use synthetic data only.
4. Never paste credentials, private datasets, employer code, or proprietary schemas.
